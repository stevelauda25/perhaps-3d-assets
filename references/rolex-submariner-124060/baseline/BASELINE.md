## Template for the next Submariner variants (date window, green bezel, two-tone: rows 126610LN, 126610LV, 126613LB, 126613LN) and the Sea-Dweller 126600 / Deepsea 136660 (43/44 mm)

Photos are already in place (untracked) for the variants: `references/rolex-submariner-date-126610ln/` etc. (same 1920 x 2857 RGBA upright render host, one camera). Check first, before reusing the template numbers: the alpha mask of the variant against this one (silhouette difference below ~60/255, lug rows 900 / 1988, coin-edge left tip x 492.6, crown guard line x 1466); the Submariner Date case is the same 41 mm case, so the geometry should hold within a few px, but the Sea-Dweller (43 mm, 126600) and the Deepsea (44 mm, 136660) have another case, scale, lug length, crown (guards / helium valve at 9) and bezel (Ringlock / 60-minute with no coin edge on the Deepsea): treat them as a FOLLOWER of the step with a re-measured `measure` file, plus a code copy only for the helium escape valve (see below).

```sh
# Submariner Date / green / two-tone: key = <sku>[-variant], ref folder = references/rolex-submariner-date-<sku> (check the folder name in ls references)
k=126610ln; ref=rolex-submariner-date-$k; photo=$(ls references/$ref/*_original.png)
sed "s#rolex-submariner-124060/rolex-124060_original.png#${photo#references/}#" config/watches/rolex-submariner41-124060-measure.json > config/watches/rolex-submariner41-$k-measure.json   # then re-measure: see below
sed "s/124060/$k/g; s/Submariner 124060 (41 mm steel, black dial, black Cerachrom bezel, Oyster bracelet, no date)/Submariner Date $k (...)/" config/watches/rolex-submariner41-124060.json > config/watches/rolex-submariner41-$k.json
sed "s/124060/$k/g; s/rolex-submariner-124060/$ref/g" jobs/rolex-submariner41-124060.json > jobs/rolex-submariner41-$k.json
python3 -B -m pipeline.rolex_submariner41_prep $k                    # trace (silhouette, hand outlines), dial_photo.jpg, steel_photo.jpg (native, no scaling)
python3 -B -m pipeline.jobs validate jobs/rolex-submariner41-$k.json   # needs references/$ref/REFERENCE_PLAN.md (write it from this one) before it validates
python3 -B -m pipeline.jobs run jobs/rolex-submariner41-$k.json --force
cp outputs/jobs/rolex-submariner41-$k/rolex-submariner41-$k.glb models/watches/<the published glb path from rolex_map.json>
python3 -B -m pipeline.glb_audit models/watches/<glb> /tmp/x.md
```

**Template (keep as is, same for every Submariner / Sub Date colour):** `pipeline/steps/watch_rolex_submariner41.py`, `pipeline/rolex_submariner41_prep.py`, the kit preset, the measure file's structure and, in the spec, the whole geometry: case (body_z 7.2, tip_z 3.3, ramp from 17, bevel 0.35, tips 23.0 / 24.75), bezel (z0 7.0, 120 teeth x 8 samples, flute depth 0.2, z_inner 8.2 / z_insert 8.6 / z_rim 8.65 / z_coin_out 7.8, chamfer 0.25), crystal, dial z, crown (16 flutes, z 4.4), hub, bracelet (columns outer / centre / outer, gap 0.06, z levels, bounds, pieces), pose, heights, materials, steel emission 0.29 (+ bezel emission 0.27) and hands emission 0.36. The Oyster bracelet and the case are shared by the whole Submariner 41 family.

**Per photo (re-measure, never trust the 124060 numbers):**
1. `measure.photo` and the ids in spec / job (the sed above). `case_centre_x`, `case_edge_left_x`, `ring_centre_px` and `rings` (circle fits as described in this baseline's measure note: radial edge scans about the pivot, iterative circle fit; the Date has the same rings, a green bezel changes only the insert colour) and `tip_rows_px`, crown box and `crown_rows`.
2. `hands`: the render time is 10:09:30 on all Rolex renders, so the angles (305.5 / 63.55 / 186.3) will hold: overlay the traced outlines (draw `trace.hands[name].outline_mm` on the photo, 3x crops) before changing the ROI shapes; the Date hands are the same Mercedes / sword hands, a lume-colour change is texture only.
3. Emissions: dial (black 0.28; a green / blue / two-tone dial or a sunburst needs its own trial: dial plate mean within ~1-2 %, and check centre vs rim for gradients), steel 0.29, bezel (black insert 0.27; a green insert or a gold ring (126613LB / LN: yellow-gold bezel ring and gold centre links, `steel_photo` carries the gold, so the steel and bezel emission may need +0.02..0.04) is re-tuned by region means: insert, rim, coin ring, case, bracelet outer / centre columns).
4. Bracelet: two-tone (126613LB / LN) has the SAME link layout with gold centre links; re-read the joints only if they differ from the table in `REFERENCE_PLAN.md` by more than 2 px in a 3x strip crop.
5. `sources.md` row text and the dial / bezel description in `REFERENCE_PLAN.md`; if the photo's colours differ from the tracker's variant, say so in the report.

**What the date window with a Cyclops needs (126610LN / LV, 126613LB / LN; not in this build):** the dial map already carries the window, the date numeral and the missing 3 o'clock index (native photo), so the window itself costs nothing. Add to the spec a `date` section and in a COPY of the step (variant-named: `watch_rolex_submariner41_date.py`, so this template stays untouched) a `cyclops` mesh: a rounded rectangle at the window (centre and size from the photo: the lens is about 5.1 x 3.3 mm, centre about 6.9 mm right of the pivot, z above the crystal by about 0.15 mm) built with `slab` plus a shallow dome (two or three offset rings so the edge reads as a bevel), using the `steel_photo` material (front projection of the lens as photographed, including its bright edge) with the same emission as the dial. A window frame ring (polished steel, 0.15 mm) can be a thin `strip` around it. Measure the lens outline from the photo (bright edge, 6x crop) and the date numeral stays texture. Check the hands do not cross the lens in the photo (they are below it at 10:09). Triangle budget stays about +300.

**Sea-Dweller 126600 (43 mm) / Deepsea 136660 (44 mm):** anchor the scale again (`case_mm` 43 / 44 and `case_edge_left_x` from the bezel tip or case flank of that photo, mirror about its `case_centre_x`; the kit preset's `scale_px_per_mm` = S / 2 and `center_px` = the new pivot / 2 offset), re-measure rings, crown box, lug rows, bracelet joints (these bracelets are wider at the lugs and end in a different clasp end link: measure it from the photo), and add the helium escape valve at 9 o'clock as an extra mesh (a short cylinder lathe on the 9 o'clock axis like the crown, projected photo); if the Deepsea / Sea-Dweller bezel shows no coin edge in its photo (check the 6x crop; set `bezel.flute_depth` to 0 and keep `rim_out` = `bezel_tip`, or use the plain ring lathe of the Oyster Perpetual step; both are decisions from the photo, not assumed here); the Maxi dial and hands may differ (Sea-Dweller hands are Mercedes too, the Deepsea has a thicker dial print): trace new hand ROIs.

Rolex plan (other families share parts): this step and spec cover the rotating-bezel Oyster-case Rolex (Submariner, Sea-Dweller, GMT-Master II with a two-colour insert: texture only, a 24-hour insert and the 4-pointer hand are texture / a fourth traced polygon) and the Oyster bracelet columns; Jubilee / President bracelets need only another `strap.bracelet.columns` / `bounds_x_mm` / `pieces_mm`.
