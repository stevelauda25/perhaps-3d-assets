## Template for the next Pelagos 39 variants

No later variants are queued; the registry entry `m25407n` already points at `tudor-pelagos-39` / `tudor-pelagos39` / 39 mm, so a variant (e.g. another -00xx dial) is added by:

```sh
cp config/watches/tudor-pelagos39-m25407n-0001-measure.json config/watches/tudor-pelagos39-<sku>-measure.json   # check the values on the new photo (pivot 449, 594; rings; crown; hands)
python3 -B -m pipeline.tudor_pelagos39_prep <sku>        # 2x copy, trace, dial_photo.jpg, steel_photo.jpg (corner logos are ignored)
cp config/watches/tudor-pelagos39-m25407n-0001.json config/watches/tudor-pelagos39-<sku>.json   # change model, note, trace, dial_map, steel_map, dial.emission, hands.emission
cp jobs/tudor-pelagos39-m25407n-0001.json jobs/tudor-pelagos39-<sku>.json                       # replace the id / spec / trace strings; keep step watch_tudor_pelagos39 and the kit preset when the pivot is (449, 594)
python3 -B -m pipeline.jobs validate jobs/tudor-pelagos39-<sku>.json && python3 -B -m pipeline.jobs run jobs/tudor-pelagos39-<sku>.json --force
cp outputs/jobs/tudor-pelagos39-<sku>/tudor-pelagos39-<sku>.glb models/watches/tudor-<sku>.glb
```

Same for any Pelagos 39 photo with this crop (pivot (449, 594), 39 mm tooth tips at 270.8 px): rings, crown, case tips, bracelet columns / joints / bounds, hand profiles, materials, pose and steel emission 0.31. Per variant: dial map (comes with the photo), dial emission (0.29 for the black dial: check dark and bright regions both ways, the response is nonlinear), `hands.emission` (0.355), hand angles and lengths if the time differs (axis fit by row symmetry at 1 px; the minute tip touches the 2 o'clock index, so measure the blade only up to about s 145), bracelet joints if the strap differs (brightness-step scans down x 355 / 450 / 545 plus 3x crops: pieces list is [y0, y1] per column kind, top and bottom, mm = px / 13.8872 about the pivot). A different bracelet: set `columns` / `bounds_x_mm` / `pieces_mm`; a continuous strap = `columns: ["strap"]`, `pieces_mm.strap`, `z_strap`.
