## Template for the next Omega Aqua Terra variants (other dials, bracelets, 38 / 41 mm)

The prep, step and kit preset are generic: a variant with the same camera, case and bracelet layout needs only new measure / spec / job JSON plus a copy of the prep with another MODEL name. Nothing of this build is to be edited, copy it.

```sh
sku=<lower-case sku, letters and digits only>             # e.g. 22010412101001 (normalised 220.10.41.21.01.001)
ref=references/omega-seamaster-aqua-terra-150m-41-$sku    # folder that already holds omega-$sku_original.png
cp pipeline/omega_aquaterra41_prep.py pipeline/omega_aquaterra41_<variant>_prep.py   # edit MODEL (ref, name e.g. omega-aquaterra41-<variant>, case_mm) and the default sku
cp config/watches/omega-aquaterra41-22010412103005-measure.json config/watches/omega-aquaterra41-<variant>-$sku-measure.json   # MEASURE every value again on the new photo (list below)
python3 -B -m pipeline.omega_aquaterra41_<variant>_prep $sku    # 2x copy, trace, dial_photo.jpg, steel_photo.jpg
cp config/watches/omega-aquaterra41-22010412103005.json config/watches/omega-aquaterra41-<variant>-$sku.json   # new model, trace, dial_map, steel_map, hands, crown, ring_centre_mm, emissions, bracelet joints
cp jobs/omega-aquaterra41-22010412103005.json jobs/omega-aquaterra41-<variant>-$sku.json     # replace the id / output / spec / trace / glb strings; step stays watch_omega_aquaterra41
cp config/presets/watch_kit_white_front_omega_aquaterra41.json config/presets/watch_kit_white_front_omega_aquaterra41_<variant>.json   # scale = 2 x px_per_mm of the trace, center_px = 2 x pivot
python3 -B -m pipeline.jobs validate jobs/omega-aquaterra41-<variant>-$sku.json && python3 -B -m pipeline.jobs run jobs/omega-aquaterra41-<variant>-$sku.json --force
cp outputs/jobs/omega-aquaterra41-<variant>-$sku/omega-aquaterra41-<variant>-$sku.glb models/watches/omega-$sku.glb
```

**Template (keep as is):** the step `pipeline/steps/watch_omega_aquaterra41.py` (case from the silhouette with integral lugs, one-ring polished bezel lathe with a chamfer, crystal, dial lathe with the photo map, solid or skeleton hand `parts` and solid `profile` seconds hand, crown, bracelet columns with `bounds_x_mm`, `pieces_mm`, `edge_from` and `backing_material`), the kit lighting and camera (only scale and centre change), materials (`steel_gap`, `lume`, `crystal`), pose and depth scale 0.35, heights (`case`, `bezel`, `crystal`, `dial`, `hands.z`, `crown.z`), steel emission 0.30, hands emission 0.43, bracelet `gap` 0.06 / `groove` 0.1 / bevel 0.15 and `backing_material` steel_photo, the cmp / regions conventions (frame = 2x photo frame).

**Per watch (re-measure on the photo, never copy):**
- Photo: 1024 x 1024 RGBA PNG, upright render with a slight tilt, crown at 3. Positions are in continuous px (pixel i spans [i, i+1]). The bracelet runs off the image at 12 and 6 (the prep clamps the steel-map crop).
- Scale: `case_width_px` = left silhouette minimum mirrored about `case_axis_px` (left + right edge of one row at the crown-free rows 426..433 and 526..529) = the case diameter of the Catalog row; do not fit a circle (cushion case).
- Pivot: intersect the centre lines of the hour, minute and seconds axes (rotated strips, saturation threshold against the dial colour; a silver or white dial needs another criterion, e.g. brightness); rings: bezel outer edge circle by edge points on 5 degree rays (r 256..270), inner rim by the bright line (r 219..228); `ring_centre_mm` = their mean minus the pivot.
- Hands: solid `parts` (signed outline from half widths per 3 px, lume strip / triangle from the pale-blue mask) per hand; the seconds hand as a profile + lume triangle. Colour comes from the projection.
- Crown, lugs: crown box x0 / x1 / y0 / y1 from alpha rows, `tip_rows_px` = rows where the silhouette widens / narrows at the lugs (`tip_top` + `tip_bottom` multiple of 0.25 mm).
- Bracelet: column x joints and link ranges from brightness scans of the column centres, top and bottom separately; another column layout only changes `columns`, `bounds_x_mm` and `pieces_mm`.
- Dial: the teak pattern, print, indices and date window are part of the 2x dial photo map; dial emission 0.365 for this blue gradient dial (a black dial wants about 0.30; check both ways, the response is nonlinear).
- Emissions: check region ratios with a regions script (dial dark / mid / print, outer ring, bezel, flank, lugs, bracelet columns, crown, whole watch).
