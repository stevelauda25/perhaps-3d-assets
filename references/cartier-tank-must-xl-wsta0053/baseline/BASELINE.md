## Template for the next Cartier variants

The same recipe serves any Cartier whose photo is a 750 x 750 straight-on JPEG with a light background (Tank Must, Tank Francaise, Santos, ...). Santos de Cartier WSSA0018 follows next: copy this step / prep / preset and adapt the case outline and bezel (see "Cartier-specific" below). Commands for a new SKU `<sku>` (lower case, letters and digits only) in folder `references/cartier-<slug>-<sku>/`:

```sh
# 1. photo saved as references/<folder>/cartier-<sku>_original.jpg (never edited); write sources.md and REFERENCE_PLAN.md like this folder's
cp config/watches/cartier-tankmustxl-wsta0053-measure.json config/watches/cartier-tankmustxl-<sku>-measure.json   # then re-measure every px value on the new photo
# prep: copy pipeline/cartier_tankmustxl_prep.py to pipeline/cartier_<name>_prep.py and change only the folder / name / photo-name constants (REF, NAME, SRC, UP)
python3 -B -m pipeline.cartier_tankmustxl_prep <sku>          # mask, 2x copy, trace, dial_photo.jpg, steel_photo.jpg
cp config/watches/cartier-tankmustxl-wsta0053.json config/watches/cartier-tankmustxl-<sku>.json   # paths with <sku>, model, note, verified_mm, hands profiles, crown profile, emissions
cp jobs/cartier-tankmustxl-wsta0053.json jobs/cartier-tankmustxl-<sku>.json                           # replace the id string everywhere (incl. references and glb path)
cp config/presets/watch_kit_white_front_cartier_tankmustxl.json config/presets/watch_kit_white_front_cartier_<name>.json   # only if the pivot differs (see below)
python3 -B -m pipeline.jobs validate jobs/cartier-tankmustxl-<sku>.json && python3 -B -m pipeline.jobs run jobs/cartier-tankmustxl-<sku>.json --force
cp outputs/jobs/cartier-tankmustxl-<sku>/cartier-tankmustxl-<sku>.glb models/watches/cartier-<sku>.glb
```

Variants of the same Tank Must case (other dial, other size listed as XL): the step, the prep and the preset are spec / measure driven, so a new SKU needs only its own measure, spec and job.

Template (same for any Tank Must XL photo with this crop; verify by diffing the render against the 2x photo padded with offset (+64, +62) for pivot (367.5, 368.5)): the geometry values of the spec (`case` z values and bevels, `crystal`, `dial.z`, `pose`, `bracelet` z / gap / bevel / backing, `materials`), the step's part structure, the kit preset camera, emissions as a start (steel 0.27, dial 0.34, hands 0.32), the mask method. Per watch in the measure JSON (px of the 750 x 750 photo): `pivot` (hub centre), `anchor` (listed case width and lug-to-lug height; the scale comes from the width on the silhouette between the brancard outer edges, rows 260..340 of the mask, so adjust `mid` in the prep if the case is shorter), `brancard.inner_*_x`, `bars`, `dial_rect`, `crown` box and cabochon, `hub_r`, hand tips and tails, `pieces_px` (bracelet piece rows per column kind and side), `centre_x_px` (vertical joint lines). Per watch in the spec: `verified_mm`, hand `profile` lists (mm along the hand from the pivot, half width; the last point is replaced by the traced length) and `hands.z`, `crown.profile_mm` ([radius, x] in mm, generated from px with the trace scale), emissions per dial colour (tune from region means, check both ways: the response is nonlinear and the dial / steel / hands are separate materials), `steel_map` / `dial_map` paths.

Cartier-specific (what differs from the Tudor recipe):
- **Mask from the JPEG**: no alpha, so the prep flood-fills the light background from the border (neighbour tolerance 4 on a gradient background with a soft shadow), cleans it (close, fill holes, largest component, median 3, Gaussian 0.7) and writes `silhouette_mask.png`; the steel map composites the photo over grey with that alpha. Check the mask on a gridded overlay at the case shoulders, bracelet ends and crown before building; raise or lower the tolerance if the shadow leaks in or a bright highlight on the steel is cut away.
- **Case outline**: rectangular, no pivot-centred rings. The scale is anchored on the listed width (31 mm) and the height is only checked. The case is built from the trace (`case.*`): brancards from the silhouette outer edge to a measured inner edge, bars between them, a dial plane over the opening. For a round or cushion case (Santos is squarish with a bezel and visible screws) replace the bars / brancards by the bezel ring and lug slabs of the Tudor BB54 step and keep the dial map, crown and bracelet code.
- **Pivot not at the dial centre**: the hands pivot is the origin (measured from the hub), the dial plane and its map are placed by the measured dial rectangle, so an off-centre pivot (here 118.5 px below the opening top and 134.5 px above its bottom) costs nothing.
- **Crown**: lathe about the 3 o'clock axis from a measured [radius, x] profile (steel faceted part plus sapphire cabochon); the studs and the blue come from the projected steel photo.
- **Hands**: blue steel sword hands from half-max profiles of the blue-minus-red channel in the rotated hand frame (hands are only 3 to 4 px wide at 1x); the photographed hands stay in the dial map, the 3D hands (0.05 mm wider) carry the projected photo so the blue comes from it; no lume.
- **Dial**: a flat 2x photo map on the dial opening (nothing printed is geometry); the railroad chapter ring, guilloche, Roman numerals and date window are all texture.
- **Bracelet**: three columns (outer / centre / outer) in flat pieces at brightness-minimum joints measured down a few columns, top and bottom separately; the outer edge is clamped to the brancard inner edges; the backing runs 0.3 mm under the case bar so no joint shows the white background.
