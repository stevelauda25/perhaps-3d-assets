# Baseline: PATEK PHILIPPE Calatrava 6007G blue (saved 2026-11-07, awaiting designer approval)

Front-relief build on the 40 mm white gold / black and blue dial / black leather strap catalogue render (Catalog 2 row 80, "White gold, blue"): the Breitling Navitimer 41 recipe (own step and prep copy) minus the chronograph parts, with a smooth polished bezel and a free-polygon central seconds hand. Three correction passes, all emission tuning (the geometry matched on the first build; strap bevel reduced from 0.25 to 0.12 mm). This build sets the **Calatrava 6007G template** (the red variant, row 81, follows it). Approval is the designer's; this file is not a similarity score.

## Template for the next Calatrava 6007G variants (red, row 81)

The red variant (`6007G`, "White gold, red", photo `references/patek-calatrava-6007g-red/patek-6007g-red_original.png`) follows with these files. The published name is `models/watches/patek-6007g-red.glb`.

```sh
var=6007g-red                                                  # variant key = folder suffix = file suffix
ref=references/patek-calatrava-$var                            # already holds patek-$var_original.png
cp config/watches/patek-calatrava6007g-6007g-blue-measure.json config/watches/patek-calatrava6007g-$var-measure.json   # then RE-MEASURE the per-photo values (list below)
python3 -B -m pipeline.patek_calatrava6007g_prep $var          # trace (silhouette, pockets), dial_photo.jpg, steel_photo.jpg (native crops)
cp config/watches/patek-calatrava6007g-6007g-blue.json config/watches/patek-calatrava6007g-$var.json    # replace the trace / dial_map / steel_map paths and model; change the per-variant values only
sed 's/6007g-blue/'$var'/g' jobs/patek-calatrava6007g-6007g-blue.json > jobs/patek-calatrava6007g-$var.json  # id, output, spec, trace, glb, REFERENCE_PLAN paths; step stays watch_patek_calatrava6007g
# preset: reuse config/presets/watch_kit_white_front_patek_calatrava6007g.json if the new photo has the same case circle (scale 31.3175 px/mm) and pivot; otherwise copy it and set scale_px_per_mm = 0.75 x the new px/mm (the pivot is the frame centre)
python3 -B -m pipeline.jobs validate jobs/patek-calatrava6007g-$var.json && python3 -B -m pipeline.jobs run jobs/patek-calatrava6007g-$var.json --force
cp outputs/jobs/patek-calatrava6007g-$var/patek-calatrava6007g-$var.glb models/watches/patek-$var.glb
```

**Template (keep as is):** the step `pipeline/steps/watch_patek_calatrava6007g.py` (case slab from the silhouette with boolean pockets, polished bezel lathe from `bezel.profile_rz_mm`, crystal, dial lathe, profile hands with `offset_mm`, free-polygon seconds hand, hub cap, fluted crown, leather strap), the prep `pipeline/patek_calatrava6007g_prep.py` (maps are native-size crops; the step reads the map scale from `steel_photo.json`), kit lighting and camera, materials, pose and depth scale (0.35), heights (`case`, `bezel`, `crystal`, `dial`, `hands.z`, `hands.hub`, `crown.z`), steel emission 0.275, strap emission 0.20, hands emission 0.34 (the hands are the photographed grey / white, red does not change them), dial emission 0.31 for a black dial (check another colour both ways), the comparison conventions (photo scaled 0.75 about the pivot into the 2048 frame, composited on white, region means in sRGB grey).

**Per watch (re-measure on the photo, never copy):**
- Scale: circle fit through the case silhouette (left rows around the pivot, both sides rows about 1090..1180 and 1395..1470, crown rows excluded) -> `bezel_out_circle_px` = [cx, cy, r], r = 20 mm; `mirror_axis_x_px` = cx; crown rows -> `mirror_rows_px`.
- Pivot: hub disc centre of the seconds hand; ring centre: circle through the bezel inner edge (radial scans, first bright radius after the dark minute track) -> `rings`, `ring_centre_mm`.
- Hands: hour / minute angle, offset and lume range from a PCA of the bright lume pixels in a narrow window around the axis (iterate); body half widths from rotated strips (edges where the grey falls below 50) and the flat tips and tail ends from the s-profile along the axis; the seconds hand from a colour mask (axis from the centroid fit of the pointer and the tail, hub disc circle, widths) -> `hands.profile`, `hands.offset_mm`, `hands.polygons.seconds` (rebuilt with the polar construction: tail rectangle, hub circle, pointer), `hub_r`.
- Crown box (x, y extents of the silhouette beyond the case circle), `fluted_to_mm`.
- Strap and lugs: lug top / bottom rows (`tip_rows_px`, `case.tip_top` / `tip_bottom`), `strap.leather.edge_from` (first strap-wide rows beyond the lugs), `pieces_mm` (leather lower end at the top, leather upper end at the bottom, alpha ends minus 2 px), `pocket_rows_px` (rows where the alpha runs read lug | lining | lug with gaps over 8 px).
- Emissions: region ratios with the list above (check steel, strap top and bottom separately, dial dark floor and bright print, hands, the coloured seconds hand and the stitching / lining), keep the template values unless a region is off by more than 4 percent.
