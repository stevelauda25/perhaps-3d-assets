## Template for the next Day-Date 40 variants (none queued; for a future Day-Date / President model)

No further Day-Date row is in the queue (228238 skipped). If one is added (same camera and case, other dial / metal), reuse the step, prep and kit preset READ-ONLY and copy only per-photo JSON:

```sh
key=<sku>   # e.g. 228238 ; photo in references/rolex-day-date-40-<sku>/rolex-<sku>_original.png (check the alpha mask against this one: same silhouette => the whole geometry holds)
sed "s/228235/$key/g" config/watches/rolex-daydate40-228235-measure.json > config/watches/rolex-daydate40-$key-measure.json
sed "s/228235/$key/g" config/watches/rolex-daydate40-228235.json > config/watches/rolex-daydate40-$key.json
sed "s/228235/$key/g" jobs/rolex-daydate40-228235.json > jobs/rolex-daydate40-$key.json
python3 -B -m pipeline.rolex_daydate40_prep $key && python3 -B -m pipeline.jobs run jobs/rolex-daydate40-$key.json --force
cp outputs/jobs/rolex-daydate40-$key/rolex-daydate40-$key.glb models/watches/rolex-$key.glb
```

**Template (keep):** the step, prep, kit preset, the measure file's scale / pivot / rings / flutes (76) / crown / silhouette rows / bracelet joints, and the spec's whole geometry (case, bezel heights, crystal, crown, President bracelet columns / pieces / z / `round_outer`, pose, steel emission 0.265). **Per dial / metal (re-measure):** `measure.photo`, the Cyclops outline if the lens differs, the hand polygons (the gold hands here are drawn from edge scans; for another time / colour re-scan angles, tips and half widths with perpendicular profiles), dial emission (0.29 for this dark brown; tune the plate mean to ~1.00), steel emission (gold: 0.265; check bezel and bracelet ratios), `sources.md` row text and the dial description in `REFERENCE_PLAN.md`.

The President bracelet (column list outer / centre / outer; `pieces_mm` per column and side, `shave.<kind>` false when the piece ranges already exclude the gaps, `round_<kind>` for the barrel rise, `backing_material` steel_photo) and the Datejust-style fluted bezel (facets with long / short boundaries) in this step are reusable for other Rolex President / fluted-bezel models (Datejust 41 Jubilee has its own step).
