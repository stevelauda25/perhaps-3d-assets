## Template for the next Sea-Dweller variants (Deepsea 136660 D-Blue, 44 mm)

Use this build as the template; the step and prep are done and generic (spec / measure / trace driven; they are variant-named for the Sea-Dweller family and are used read-only by key). The Deepsea photo is `references/rolex-sea-dweller-deepsea-136660/rolex-136660_original.png` and its GLB goes to `models/watches/rolex-136660.glb` (`rolex_map.json` pos 56).

```sh
k=136660; ref=rolex-sea-dweller-deepsea-$k; photo=references/$ref/rolex-${k}_original.png
python3 - "$k" "$photo" "$ref" <<'PY'
import json, sys
k, photo, ref = sys.argv[1:4]
m = json.load(open("config/watches/rolex-seadweller43-126600-measure.json")); m["photo"] = photo
json.dump(m, open("config/watches/rolex-seadweller43-%s-measure.json" % k, "w"), indent=1)
s = json.dumps(json.load(open("config/watches/rolex-seadweller43-126600.json"))).replace("126600", k)
json.dump(json.loads(s), open("config/watches/rolex-seadweller43-%s.json" % k, "w"), indent=1)
j = json.dumps(json.load(open("jobs/rolex-seadweller43-126600.json"))).replace("rolex-seadweller43-126600", "rolex-seadweller43-" + k).replace("rolex-sea-dweller-126600", ref)
json.dump(json.loads(j), open("jobs/rolex-seadweller43-%s.json" % k, "w"), indent=1)
PY
# 1. re-measure the measure file (see below), edit model / note / verified_mm / case_mm text of the new spec, job and measure by hand
python3 -B -m pipeline.rolex_seadweller43_prep $k                        # trace, dial_photo.jpg, steel_photo.jpg
python3 -B -m pipeline.jobs validate jobs/rolex-seadweller43-$k.json      # needs references/$ref/REFERENCE_PLAN.md (write it from this one)
python3 -B -m pipeline.jobs run jobs/rolex-seadweller43-$k.json --force
cp outputs/jobs/rolex-seadweller43-$k/rolex-seadweller43-$k.glb models/watches/rolex-$k.glb
python3 -B -m pipeline.glb_audit models/watches/rolex-$k.glb /tmp/x.md
```

**Per photo (re-measure, never trust the 126600 numbers):**
1. `measure.photo`, `case_mm` 44, `case_centre_x` (lug edges at two rows, mirrored), `case_edge_left_x` = the leftmost silhouette column of the coin / bezel edge at the pivot row (subpixel from the alpha), `pivot` = hub screw (look at a 6x crop of the hub), `ring_centre_px` and `rings` by iterative circle fits of radial edge scans about the pivot (gradient maxima in windows around the expected radii, rejecting outliers, on the black ceramic sectors for the insert and rim edges: dial edge r, flange edge, insert in / out, rim out, tips; the scan script lived in the scratchpad only, recreate it from this sentence); expect the ring centres a few px above the pivot (taller case). `tip_rows_px` = first row of the lug step at top and bottom (alpha), `crown` / `crown_rows` (crown box from a 5x crop, the guard plateau line from the alpha rows above and below the crown). Spec `verified_mm` diameter 44 and lug_to_lug = tip_top + tip_bottom (multiples of 0.25 mm).
2. Bezel: count the flutes of the coin edge (silhouette ripple of the radius over the left sector: FFT peak, here 60 per turn with a ridge at 3.3 deg mod 6 deg: `bezel.teeth`, `samples_per_tooth` (N = teeth x samples about 960), `flute_phase_deg`, `flute_depth` from the ripple); if the Deepsea Ringlock bezel shows no coin edge in a 6x crop set `flute_depth` to 0 (the ring then follows `rings.bezel_tip` as a plain ring) and decide from the photo.
3. `hands`: angles (10:09:30: 305.5 / 63.55 / 186.3 held here), traced by ROI: overlay `config/watches/rolex-seadweller43-<k>-trace.json` hand outlines on 4x crops before changing the ROI shapes; the Deepsea hands are the same Mercedes / sword family but longer (check the minute tip s and the seconds tail dot / lume ring). Hub radius 18 px held.
4. Dial: the D-Blue dial is a gradient from blue to black (texture), its own emission trial (dial plate mean within ~1 %, check centre vs rim and the dark floor); steel 0.29 / bezel 0.27 / hands 0.35 were within 2.3 % here.
5. Bracelet: Oyster / Glidelock + Fliplock end: joint rows from gradient scans of the mean column profiles (outer columns x ~790..830, centre ~900..1020, top and bottom), read with the template's convention (outer / centre joints = the sharp edge or the dark dip: compare against this build's rows 736.5 / 2206 / 2386 / 2502 and 703 / 842 / 2059.5 / 2264 / 2428.5 / 2517.5 on the same read), column lines x 854.8 / 1064.3 here; `strap.bracelet.pieces_mm` = [y0, y1] ranges in mm from the pivot, top and bottom separately, `bounds_x_mm` = [|y|, x1, x2] lists.
6. Helium escape valve: not visible in the 126600 render (hidden behind the bezel on the left flank). If the Deepsea render shows the valve in the silhouette or on the case, the silhouette-cut case slab already carries its outline (as the Omega Diver); a valve cylinder is only worth a mesh if the photo shows a clear bump.
7. `sources.md` and `REFERENCE_PLAN.md`; if the photo's colours differ from the tracker's variant (D-Blue), say so in the report.
