Catalog 2 line: Patek Philippe, Calatrava, 6007G, 40mm, White gold, red, Leather strap, Brand New, 34000 / 35700 (row 81; same SKU as row 80 "White gold, blue", so the published file carries the variant: `models/watches/patek-6007g-red.glb`).
The "red" variant reads as a black dial with red minute-track marks, red guilloche-ring markers and a red central seconds hand; the strap is black embossed leather (a woven checker emboss, not the blue photo's pattern) with red stitching and a red lining between the lugs.
Patek Philippe image rights remain with the manufacturer; reference use only.
