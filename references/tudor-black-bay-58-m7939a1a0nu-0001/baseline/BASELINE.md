## Template for the next Black Bay 58 variants (burgundy M7939A1A0RU-0001)

Registry entry `m7939a1a0ru` already points at `tudor-black-bay-58` / `tudor-bb58` / 39 mm. Photo, REFERENCE_PLAN.md and sources.md are written per variant at `references/tudor-black-bay-58-<sku>/`. Commands for `<sku>` = `m7939a1a0ru-0001`:

```sh
cp config/watches/tudor-bb58-m7939a1a0nu-0001-measure.json config/watches/tudor-bb58-m7939a1a0ru-0001-measure.json   # then check the values below on the new photo
python3 -B -m pipeline.tudor_bb58_prep m7939a1a0ru-0001      # 2x copy, trace, dial_photo.jpg, steel_photo.jpg (logo / ticks in the PNG are ignored)
cp config/watches/tudor-bb58-m7939a1a0nu-0001.json config/watches/tudor-bb58-m7939a1a0ru-0001.json
# in the new spec change: model, note, trace, dial_map, steel_map (paths with m7939a1a0ru-0001), dial.emission, hands.emission, and whatever the checks below show
cp jobs/tudor-bb58-m7939a1a0nu-0001.json jobs/tudor-bb58-m7939a1a0ru-0001.json                                    # replace the id string everywhere (incl. references), keep step watch_tudor_bb58
# kit preset: reuse config/presets/watch_kit_white_front_tudor_bb58.json as is when the pivot is at (451, 613); otherwise copy it and set the scale / centre
python3 -B -m pipeline.jobs validate jobs/tudor-bb58-m7939a1a0ru-0001.json
python3 -B -m pipeline.jobs run jobs/tudor-bb58-m7939a1a0ru-0001.json          # add --force after regenerating the maps
cp outputs/jobs/tudor-bb58-m7939a1a0ru-0001/tudor-bb58-m7939a1a0ru-0001.glb models/watches/tudor-m7939a1a0ru-0001.glb
```

Template (same for any Black Bay 58 photo with this crop and the 10:10:38 pose; verify by diffing the render against the 2x photo padded with offset (+122, -202) for pivot (451, 613)): in the measure JSON the pivot, `case_edge_left_x` (180.5), `rings`, `crown`, the hand tips / tails / `hub_r` / lumes, `tip_rows_px`; in the spec the case (tips, z values), bezel, crystal, `ring_centre_mm`, crown, the bracelet section (columns, `bounds_x_mm`, `pieces_mm`, z values), hands (profiles and lume polygons), materials, pose, steel emission 0.31 / specular 0. If the new photo has the pivot elsewhere, re-measure the pivot (hub pin hole at 8x), scale (`case_edge_left_x`), the dial circle centre (circle fit on the dial edge, rehaut edge and bezel steel edge -> `ring_centre_mm`), rings, crown and hand axes first; the preset and the padding offset follow the pivot (2x photo pivot at (1024, 1024)).

Per variant: the dial map and bezel colours (they come with the photo; a burgundy dial and burgundy bezel insert are texture only, so only emission changes), dial emission (tune from region means: the black dial needed 0.29; a lighter burgundy dial will want more, probably 0.33-0.45, check both bright and dark areas), `hands.emission` (0.355 here: lower until hands+hub reads about 1.00, the lume saturates), hands angles and lengths if the time differs (measure the axes: fit the stem centre line in a rotated 6x crop, `hand_rows`-style row scans give the half widths; update `profile` and `lume` in mm = px / 13.8718 plus 0.03 mm on the profile), the hub radius if the hub differs, and the bracelet section if the strap differs:

- bracelet joints: measure them like here, on the new photo, top and bottom separately: brightness scans down x of each column (x 345 / 360 outer, 410 / 490 inner, 450 centre) with dark runs below about 90 grey, plus 4-6x crops with a pixel ruler; convert with 13.8718 px/mm about the pivot (mm = (px - pivot) / S). `pieces_mm.<kind>.top|bottom` = chain of [y0, y1] from the case outward, the first inner / centre piece starts at 18 mm (under the coin ring), the first outer piece starts about 0.2 mm beyond the lug tip row (`tip_top` / `tip_bottom`), the last piece ends at the bracelet end. The vertical joint lines `bounds_x_mm` are the edges at about x 388 / 430 / 470 / 512 (steel brightness steps down a few rows).
- a different strap (rubber, fabric, other bracelet): set `columns` to the column kinds left to right (one entry per column; `["strap"]` for a continuous strap with `pieces_mm.strap`, `z_strap`), `bounds_x_mm` needs one boundary less than columns (an empty list entry is fine for one column); the lug tip rows and the silhouette follow the photo.
- the registry/prep need nothing else; `python3 -B -m pipeline.tudor_bb58_prep` writes the trace (silhouette, rings, hands lengths and angles, crown) from the measure JSON.
