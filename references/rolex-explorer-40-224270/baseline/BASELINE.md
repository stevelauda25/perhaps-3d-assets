## Template for the next Explorer 40 / round Oyster-case Rolex variants (e.g. another Explorer 40 dial; same case, bezel and Oyster bracelet)

Run, per variant (key = normalized SKU; folder = references/rolex-<model>-<sku>):

```sh
key=224270; ref=references/rolex-explorer-40-224270
cp config/watches/rolex-explorer40-224270-measure.json config/watches/rolex-explorer40-$key-measure.json   # then RE-MEASURE everything marked "per photo" below; set "reference_dir"
python3 -B -m pipeline.rolex_explorer40_prep $key     # prints scale_px_per_mm, bracelet rows / pieces in mm, aperture range, map sizes
sed "s/224270/$key/g" config/watches/rolex-explorer40-224270.json > config/watches/rolex-explorer40-$key.json   # spec: model / note text, case.tip_top / tip_bottom, emissions
sed "s#rolex-explorer-40-224270#<ref folder name>#g; s/224270/$key/g" jobs/rolex-explorer40-224270.json > jobs/rolex-explorer40-$key.json
cp config/presets/watch_kit_white_front_rolex_explorer40.json config/presets/watch_kit_white_front_rolex_explorer40_$key.json   # set cameras.front_ortho.ortho.scale_px_per_mm = (trace scale_px_per_mm) / 2 and point the job's kit stage at it
python3 -B -m pipeline.jobs validate jobs/rolex-explorer40-$key.json && python3 -B -m pipeline.jobs run jobs/rolex-explorer40-$key.json --force
cp outputs/jobs/rolex-explorer40-$key/rolex-explorer40-$key.glb models/watches/rolex-$key.glb
python3 -B -m pipeline.glb_audit models/watches/rolex-$key.glb /tmp/x.md
```

(The prep reads the one `rolex-*_original.*` in the reference folder. The job uses the Air-King step `watch_rolex_airking`, unchanged.)

**Template (keep as is):** `pipeline/steps/watch_rolex_airking.py` and `pipeline/rolex_explorer40_prep.py` (read-only unless a code change is needed), kit lighting, materials, pose, heights (`case` body_z 6.6, bezel_z 8.9, chamfer_z 8.2, bezel dome dz 0.08 / 0.04, bezel_bevel 0.04, dial z 7.0, hands z 7.4 / 7.65 / 7.9, crown z 5.0, bracelet z0 / z_side / lift / piece_lift / bevels / gap 0.05), `rays` = `aperture.n` = 180, the structure of the measure file, the comparison conventions (kit frame 1280 square at half the working scale, pivot at the centre).

**Per photo (measure, never trust the 224270 numbers):** `pivot`, `anchor.rows` and `case_mm` 40; `crown_replace` (several segments are allowed: the notch line is the mirror of the left bezel flank) and the crown `base_px` / `profile_px` (per-column half heights from the alpha silhouette: radius = half the row extent at that x); `bezel_outer` (silhouette at 9, radial edges at 12 / 6) and `aperture.circle` (outer edge of the dark bevel line at 12 / 3 / 6 / 9 o'clock, then a circle through them; the radial max-gradient scan fails on the black reflection in the upper half); `hands[name].polygon_px` (strip crops rotated about the pivot, unions of discs, shafts and arrowheads rasterised at 10x and simplified; tail disc and lume head disc of the seconds hand are separate circles); `bracelet.rows_px` (dark joint lines at an outer column) and `pieces_px` (centre-link joints at the centre column, 2 px each side of the joint line; the bracelet phase differs per render: the Air-King and Explorer joints sit 0 to 30 px apart); `case.tip_top` / `tip_bottom` (lug end rounded up to 0.25 mm, sum a multiple of 0.25); emissions (dial 0.29 for this black dial, steel 0.285, bracelet 0.275 / 0.29, hands 0.40).
