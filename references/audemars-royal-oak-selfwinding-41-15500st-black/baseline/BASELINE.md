# Baseline: AUDEMARS PIGUET Royal Oak Selfwinding 41 15500ST black (saved 2026-11-07, awaiting designer approval)

Front-relief build on the 41 mm steel / black Grande Tapisserie dial / integrated steel bracelet catalogue render (the 1200 x 1626 rendition), with the Offshore Diver recipe (octagon bezel by rays, eight screws) plus an integrated bracelet built from measured seams and pin-link bars; new model-specific step and prep (three render passes after the first build). This is the **second Audemars Piguet model** and sets the **Royal Oak 41 template** (see the last section; the white variant, catalog row 84, and the grey one, row 85, follow it). The catalog gives the very same photo (`standup-1060`) to row 88 (15510ST, "Steel, black"), so this GLB is also published under that name by the lead. Approval is the designer's; this file is not a similarity score.

## Template for the next Royal Oak 41 variants (white row 84, grey row 85)

The white (catalog row 84, photo `standup-996`) and grey (row 85, `standup-1014`) Royal Oak 41 variants have the same SKU 15500ST, so the variant key carries the colour, also in the GLB name: `15500st-white`, `15500st-grey`. (Rows 89 / 90 are 15510ST with the same two photos; the lead publishes copies under those names.) The lead has to download the photo as `references/audemars-royal-oak-selfwinding-41-<key>/audemars-<key>_original.png` and `..._1200x1626.png` first (the reference folders already exist). The prep, step and kit preset are generic; a variant needs only a new measure / spec / job JSON.

```sh
key=15500st-white                                                              # or 15500st-grey; the black one is 15500st-black
ref=references/audemars-royal-oak-selfwinding-41-$key                          # holds audemars-$key_original.png and audemars-$key_1200x1626.png
cp config/watches/audemars-royaloak41-15500st-black-measure.json config/watches/audemars-royaloak41-$key-measure.json   # then MEASURE every value again on the new photo (list below)
python3 -B -m pipeline.audemars_royaloak41_prep $key                           # 2x copy, trace, dial_photo.jpg, steel_photo.jpg (MODEL constants stay: same ref prefix, name, 41 mm); check the printed scale_px_per_mm
cp config/watches/audemars-royaloak41-15500st-black.json config/watches/audemars-royaloak41-$key.json      # change model, trace, dial_map, steel_map, dial.emission, hands.emission (profile if the hands differ)
sed "s/15500st-black/$key/g" jobs/audemars-royaloak41-15500st-black.json > jobs/audemars-royaloak41-$key.json   # id / output / spec / trace / glb / reference strings; step and kit preset stay; edit model / baseline text
cp references/audemars-royal-oak-selfwinding-41-15500st-black/REFERENCE_PLAN.md $ref/REFERENCE_PLAN.md       # edit the measured values and the catalog row (also fix the paths inside)
python3 -B -m pipeline.jobs validate jobs/audemars-royaloak41-$key.json && python3 -B -m pipeline.jobs run jobs/audemars-royaloak41-$key.json --force
cp outputs/jobs/audemars-royaloak41-$key/audemars-royaloak41-$key.glb models/watches/audemars-$key.glb
```

The kit preset `config/presets/watch_kit_white_front_audemars_royaloak41.json` is shared as it is while the new photo has the same scale (7.0141 px/mm) and pivot (600.0, 792.5); if the prep prints another `scale_px_per_mm`, copy the preset and set `scale_px_per_mm` = 2 x that and `center_px` = [640, 640] (1280 frame; the pivot of the 2x photo lands at (640, 640)), and point the job's kit stage at the copy. Comparison images: pad the 2x photo so that its pivot (2 x pivot) lands at (640, 640) (an affine shift of 640 - 2 x pivot), and compare region means in grey.

**Template (keep as is):** the step `pipeline/steps/watch_audemars_royaloak41.py` (case slab from the silhouette, octagon bezel ring by rays with chamfer, eight screws, flat dial lathe, crown from `trace.crowns`, hands from profile lists, integrated bracelet from `trace.bracelet`: three gapped link columns between the seams, two continuous bars), the prep, the kit lighting / camera, materials (`steel_gap`, `lume`, `crystal`), pose and depth scale, heights (`case` body_z 6.6 / tip_z 3.4 / bezel_z 8.9 / chamfer_z 8.2 / chamfer_mm 0.3 / bezel_bevel 0.2, `crystal`, `dial` z 7.0 = ring_z, `hands.z`, `crown.z` 5.0, `bracelet` z 3.55 / bar_lift 0 / gap -0.02 / seam_shrink 0.18 / bevel 0 (flat shading) / backing), steel emission 0.31, hands emission 0.45, the comparison conventions (continuous px, the 2x pivot moved to the frame centre).

**Per variant (re-measure on the photo, never copy):**
- Photo: AP serves a 400 x 542 PNG; the working source is the `&wid=1200&hei=1626` rendition (same watch, 310 x 506 px of it). The renders of the three dials come from one model with a very similar pose, but pivot, flat edges and seams can differ by a pixel or two (tilt): do not assume the black values.
- `pivot`: from the hands (the seconds needle passes the pivot; for the hour and minute hand use the full width incl. the darker facet: a brightness threshold that cuts a facet shifts the centre line by 1 px; a white or light grey dial needs another mask: the hands are brighter than the waffle only by their polished faces, try brightness profiles across the hand, as done here) and the hub; the black photo's hands read 303.8 / 49.9 / 227.3 deg (10:07:38).
- `anchor.rows`: rows where the left flat of the case is straightest (here 786..803): the median alpha edge = 20.5 mm from the pivot; verify that the printed `scale_px_per_mm` is near 7.01 (a different value means the pivot or the flat was misread). Check the hidden right flat (743.4) is symmetric to the left one about the pivot x.
- `octagon`: left / right flats from the silhouette (right flat hidden by the crown: mirror the left one about x = pivot, check on the rows above and below the crown), top / bottom flats from the polished chamfer line at x = pivot (here 650.0 / 942.5); `opening_circle_px`: outer edge of the black dial rim on radial scans (here (599.8, 790.0) r 109.8, noisy: also check the four extreme points); `dial_flat_r_px` / `ring_in_r_px`: just inside the opening (the printed plate; no ring on this dial).
- `screws_px` and `screw_r_px`: the slot centres (small dark elongated components in the bezel zone, 126 px from the opening centre), order starts at the top right and runs clockwise.
- `crowns`: base point on the axis at the flank (743.0, 798.7), hex length / circumradius from the top / front / bottom faces (rows 776.5..821); `crown_replace`: a straight line that replaces the silhouette rows of the crown (start at the first crown row, end at the last: x 742.0 / 741.6).
- Hands: angle, length (clockwise from 12), half widths along the hand (spec profile lists in mm: hour 3.6 px, minute 4.15 px incl. the dark facet, seconds 0.7 px) and the chamfered tips; no lume objects.
- `bracelet.seams_px`: dark rows [a, b) between links (merge runs closer than 2 px; same rows for the outer and the centre columns to +-1 px) top and bottom; the first seam of each side is the junction of the case (spec `case.tip_top` / `tip_bottom` = its near edge snapped to 0.25 mm, sum a multiple of 0.25: 23.5 / 26.0 here); `bracelet.bars_px`: rows [row, left bar x0, x1, right bar x0, x1] at the case end, mid and strap end (top: 628 / 605 / 584, bottom: 975 / 1010 / 1040 / 1064 / 1083 here), read from the dark seam ends (runs along the seam rows) and the brightness steps.
- Emissions: region ratios with the list above (dial plate / bright / dark, bezel face, bracelet top / bottom, case top / bottom, crown, whole watch); a white or grey dial needs its own dial emission (try two values both ways: the response is nonlinear and the dark black dial reads best at 0.30); the steel parts stay at 0.31 unless a region ratio says otherwise.
