## Template for the next LEFT-crown GMT-Master II 40 variants

Use `pipeline/rolex_gmtmaster40_left_prep.py` and `pipeline/steps/watch_rolex_gmtmaster40_left.py` (read-only, spec / measure / trace driven) for any other left-crown photo of this camera. Copy `config/watches/rolex-gmtmaster40-126720vtnr{,-measure}.json` and `jobs/rolex-gmtmaster40-126720vtnr.json` (replace the key in the ids / paths, `photo` in the measure), then re-measure per photo: pivot and hands (identical dial photos reuse the ROIs), `case_edge_right_x` / `case_centre_x`, crown block (`crown.x0` = end next to the case, `x1` = cap end, `fluted_x`, `crown_rows.left_x`), `date.lens_px`, bracelet columns / joints, emissions. The measure keys that make it left-handed: `"crown_side": "left"`, `case_edge_right_x` (instead of `case_edge_left_x`), `crown_rows.left_x` (instead of `right_x`); the trace then holds `crown.side = -1` and positive crown distances.
