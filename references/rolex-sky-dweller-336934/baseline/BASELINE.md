## Template for the next Sky-Dweller 42 variants (none queued)

Same camera and case: reuse `pipeline/steps/watch_rolex_skydweller42.py`, `pipeline/rolex_skydweller42_prep.py` and the kit preset READ-ONLY and copy the spec / measure / job.

```sh
k=<ref>; ref=rolex-sky-dweller-$k; name=rolex-skydweller42-$k
sed "s#rolex-sky-dweller-336934/rolex-336934_original.png#$ref/rolex-$k""_original.png#" config/watches/rolex-skydweller42-336934-measure.json > config/watches/$name-measure.json   # then re-measure (below)
sed "s/336934/$k/g; s/blue dial/<dial>/; s/Oyster bracelet/<bracelet>/" config/watches/rolex-skydweller42-336934.json > config/watches/$name.json
sed "s/336934/$k/g; s/rolex-sky-dweller-$k/$ref/g" jobs/rolex-skydweller42-336934.json > jobs/$name.json
python3 -B -m pipeline.rolex_skydweller42_prep $k && python3 -B -m pipeline.jobs validate jobs/$name.json   # REFERENCE_PLAN.md needed first
python3 -B -m pipeline.jobs run jobs/$name.json --force && cp outputs/jobs/$name/$name.glb models/watches/rolex-$k.glb
python3 -B -m pipeline.glb_audit models/watches/rolex-$k.glb /tmp/x.md && python3 -B -m pipeline.zoom_check references/$ref/baseline
```

Keep as is: step, prep, preset, measure structure and the spec geometry (case, bezel flutes / radii / heights, crystal, dial z, lens levels, crown, hub, pose, hands emission). Verify by overlay that the head holds (silhouette, flange / flute circles, 70-flute phase at 9 o'clock, crown box, Cyclops outline). Per variant: `measure.photo`; the hand angles (render time may differ per photo: re-fit axes) and ROI polygons, with `hand_br_thr` 30 valid for a blue dial (a silver / white / black dial needs a grey test `thr` as in `rolex_submariner41_prep.py`: set `hand_br_thr` to null); dial / Cyclops / steel emissions by region means; Jubilee: `strap.bracelet.columns` outer / semi / centre / semi / outer as described in the Datejust 41 BASELINE template section.
