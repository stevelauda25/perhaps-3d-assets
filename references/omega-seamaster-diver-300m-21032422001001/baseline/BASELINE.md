## Template for the next Omega Diver 300M variants (bracelet 210.30.42.20.03.001, blue)

The prep, step and kit preset are generic enough that a variant normally needs only new measure / spec / job JSON plus a copy of the prep with another MODEL name; the **bracelet** version needs a column / joint layout for the strap (below). Nothing of this build is to be edited, copy it.

```sh
sku=<lower-case sku, letters and digits only>            # bracelet: 21030422003001 (normalised 210.30.42.20.03.001)
ref=references/omega-seamaster-diver-300m-$sku              # (or a slug of your choice) folder that already holds omega-$sku_original.<ext>
cp pipeline/omega_diver300m_prep.py pipeline/omega_diver300m_bracelet_prep.py       # edit MODEL (ref, name, e.g. omega-diver300m-bracelet) and SRC extension if not PNG; the default sku too
cp config/watches/omega-diver300m-21032422001001-measure.json config/watches/omega-diver300m-bracelet-$sku-measure.json   # MEASURE every value again on the new photo (list below)
python3 -B -m pipeline.omega_diver300m_bracelet_prep $sku    # 2x copy, trace, dial_photo.jpg, steel_photo.jpg
cp config/watches/omega-diver300m-21032422001001.json config/watches/omega-diver300m-bracelet-$sku.json   # change model, trace, dial_map, steel_map, hands, crown, ring_centre_mm, emissions, STRAP (kind "bracelet" + bracelet block)
cp jobs/omega-diver300m-21032422001001.json jobs/omega-diver300m-bracelet-$sku.json                  # replace the id / output / spec / trace / glb strings; step stays watch_omega_diver300m
cp config/presets/watch_kit_white_front_omega_diver300m.json config/presets/watch_kit_white_front_omega_diver300m_bracelet.json   # scale = 2 x px_per_mm of the trace, center_px = 2 x pivot of the 2x frame (use 2048 only if the whole watch fits)
python3 -B -m pipeline.jobs validate jobs/omega-diver300m-bracelet-$sku.json && python3 -B -m pipeline.jobs run jobs/omega-diver300m-bracelet-$sku.json --force
cp outputs/jobs/omega-diver300m-bracelet-$sku/omega-diver300m-bracelet-$sku.glb models/watches/omega-$sku.glb
```

(If the bracelet photo has the same camera, case and dial, the step can also be pointed at a second spec with the same prep: change only `MODEL["name"]` in the prep copy so the output folders do not collide with this build.)

**Template (keep as is):** the step `pipeline/steps/watch_omega_diver300m.py` (case from the silhouette incl. valve and crown shoulder, ringless ceramic bezel lathe, crystal, dial lathe with the photo map, skeleton hand parts + solid profile hands, crown, strap `kind` "rubber" or "bracelet" with generic `columns` / `bounds_x_mm`), the kit lighting and camera (only scale and centre change), materials (`steel_gap` with specular 0, `lume`, `crystal`), pose and depth scale, heights (`case`, `bezel`, `crystal`, `dial`, `hands.z`, `crown.z`), steel emission 0.31, hands emission 0.43, dial emission 0.30 for a black wave dial (a blue wave dial is lighter: check both ways, the response is nonlinear), the cmp / regions conventions (frame = 2x photo frame).

**Per watch (re-measure on the photo, never copy):**
- Photo: 1024 x 1024 RGBA PNG, upright render with a slight tilt / yaw, crown at 3, helium valve at 10. Positions are in continuous px (pixel i spans [i, i+1]). The strap runs off the image on this photo (the prep clamps the steel-map crop); a bracelet may end inside the image: nothing to change then.
- Scale: circle fit to the LEFT silhouette rows 400..600 (`bezel_out_circle_px` = [cx, cy, r]) = 42 mm; do not fit the right side (flank + crown shoulder). Cross-check with the strap / lug width (20 mm).
- Pivot: intersect the centre lines of the hour, minute and seconds axes (rotated strips, thresholds 150 / 235 on the dark dial; blue dial: look at the lume threshold again); hub pin hole is about 1 px lower. Rings: bezel top circle by edge points (dark to steel gradient r 250..268 on 5 degree rays, rms 0.4 px), inner rim by the bright peak at r 190..193; `ring_centre_mm` = their mean minus the pivot.
- Hands: skeleton `parts` (frame base, rails, tip piece with `mirror`, lume strips, disc / triangle) measured as half widths along the axis (px / 12.951); the seconds hand stays a solid profile + lume core. The bracelet photo may show other hand colours / lume (blue hands?): the 3D hands only add relief, colour comes from the projection.
- Crown, valve, lugs: crown box x0 / x1 / y0 / y1 from alpha rows (crown rows take the mirrored left edge, shoulders stay), `tip_rows_px` = lug top / bottom rows (`tip_top` + `tip_bottom` multiple of 0.25 mm).
- **Steel bracelet (what the bracelet variant needs):** `strap.kind` "bracelet" and a `strap.bracelet` block as in `config/watches/tudor-bb58-m7939a1a0nu-0001.json` (column-driven builder of `pipeline/steps/watch_tudor_bb58.py`, already in this step): `columns` left to right (e.g. outer, inner, centre, inner, outer for the 300M's five-link layout; read the layout from the photo: a 300M bracelet has a polished centre link flanked by two brushed rows and polished outer links), `bounds_x_mm` = [|y|, x1 .. xn-1] vertical joint lines between the columns for top and bottom (brightness scans every 10 px along the joints), `pieces_mm[column][top|bottom]` = [y0, y1] link ranges in mm from the pivot (joints from pixel-grid crops at 3 to 6x and brightness-gradient scans), `z_<column>`, `gap` (joint gap between links, 0.06), `groove` (x gap between columns, default `gap`), `z0`, `bevel`, `backing_z`, `inset`, `backing_inset`; no `lift`, no `edge_from` (outer edges come from the silhouette). Material `steel_photo` (the projected photo carries the brushed / polished look); strap emission is the steel emission. The end of a 300M bracelet and its folded clasp side: reproduce the outline from the alpha, say what stayed flat.
- Logo / print: the wave pattern, print, date window and the lume dots are part of the 2x dial photo map (the photographed hands stay in it, hidden by the 3D hands); the date window is not cut out.
- Emissions: check region ratios with `regions.py` of the scratch folder (dial dark / wave grey / print, bezel ceramic / numerals, case flank, lugs, strap columns, crown, valve, whole watch).
