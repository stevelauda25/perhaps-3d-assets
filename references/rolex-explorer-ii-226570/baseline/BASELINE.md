## Template for the next GMT-style Rolex variants (24 h hand: Explorer II other dial, GMT-Master II 40 / 41 and its bezels, Sky-Dweller)

Run, per variant (key = normalized SKU; folder = references/rolex-<model>-<sku>):

```sh
key=226570; ref=references/rolex-explorer-ii-226570
cp config/watches/rolex-explorer2-226570-measure.json config/watches/rolex-explorer2-$key-measure.json   # then RE-MEASURE everything marked "per photo" below; set "reference_dir"
python3 -B -m pipeline.rolex_explorer2_prep $key     # prints scale_px_per_mm, bracelet rows / pieces in mm, aperture ranges, map sizes
sed "s/226570/$key/g" config/watches/rolex-explorer2-226570.json > config/watches/rolex-explorer2-$key.json   # spec: model / note text, case.tip_top / tip_bottom, hands.z, emissions
sed "s#rolex-explorer-ii-226570#<ref folder name>#g; s/226570/$key/g" jobs/rolex-explorer2-226570.json > jobs/rolex-explorer2-$key.json
cp config/presets/watch_kit_white_front_rolex_explorer2.json config/presets/watch_kit_white_front_rolex_explorer2_$key.json   # cameras.front_ortho.ortho.scale_px_per_mm = (trace scale_px_per_mm) / 2 and point the job's kit stage at it
python3 -B -m pipeline.jobs validate jobs/rolex-explorer2-$key.json && python3 -B -m pipeline.jobs run jobs/rolex-explorer2-$key.json --force
cp outputs/jobs/rolex-explorer2-$key/rolex-explorer2-$key.glb models/watches/rolex-$key.glb
python3 -B -m pipeline.glb_audit models/watches/rolex-$key.glb /tmp/x.md
```

(The prep reads the one `rolex-*_original.*` in the reference folder. The job uses `pipeline/steps/watch_rolex_explorer2.py`, unchanged. The step also runs the 3-hand Air-King / Explorer 40 case: drop the `gmt` entries.)

**The GMT-style hand = data only.** Add a key to `measure.hands` (any name; its `polygon_px` = outline in px from the pivot, x right, y up, filled silhouette including the arrow head, optionally a disc at the pivot a few px larger than the hub), and the same key to the spec `hands.z` with a height between the hour and the minute hand (`{"hour": 7.4, "gmt": 7.5, "minute": 7.65, "seconds": 7.9}`; order in `hands.z` is the build order). `hands_photo` projects the photographed pixels (coloured arrow, lume interior, paint) on it. For a hand with a cut-out or a thin frame the interior stays photo, so no extra lume geometry is needed. How the outlines were traced: upsample 4x, mask = max(R,G,B) < 125 (dark hands) or R - B > 90 (orange), intersect with an oriented strip along the hand axis (angle from pivot to tip; strip |t| < 6..35 px), add filled primitives where the dial print touches the hand (discs for the Mercedes ring, tail disc and lume ring; a triangle for an arrow tip that touches text; the base disc r 33), close 5 x 5, take the external contour, `approxPolyDP` 0.6 px, store as px from the pivot.

**Template (keep as is):** `pipeline/steps/watch_rolex_explorer2.py` and `pipeline/rolex_explorer2_prep.py` (read-only unless a code change is needed), kit lighting, materials, pose, heights (`case` body_z 6.6, bezel_z 8.9, chamfer_z 8.2, bezel dz 0.06 / 0.02, crest 0.4 mm, bezel_bevel 0.04, dial z 7.0, hands z as above, crown z 5.0, bracelet z0 / z_side / lift / piece_lift / bevels / gap 0.05), `rays` = `aperture.n` = 180, the structure of the measure file, the comparison conventions (kit frame 1280 square at half the working scale, pivot at the centre). Emissions of the white dial: dial 0.325, steel 0.25, bracelet 0.24 / 0.29, hands 0.34 (a black dial needs about 0.29 as in the Explorer 40; compare the white patches: they clip at 255 when the dial is too high).

**Per photo (measure, never trust the 226570 numbers):** `pivot` (hub disc centre), `case_mm` and `anchor` (`rows` for the left flank, `right_px` = right bezel edge when the bezel is not centred on the pivot; without `right_px` the Air-King rule applies: left flank to the pivot = half the case), `crown_replace` (guard wall line behind the crown, rows from the top guard end to the bottom guard start) and the crown `base_px` / `profile_px` ([radius, px along the axis] from the base, check both shoulders in a 6x crop), `bezel_outer` (silhouette at 9, top and bottom edges at 12 / 6 from 6x crops), `aperture.face` (inner edge of the brushed bezel face at 12 / 3 / 6 / 9 o'clock: ellipse centre, half axes) and `aperture.window` (outer edge of the rehaut ring: ellipse; for a window without a bevel use `aperture.circle` as in the Explorer 40), `hands[name].polygon_px`, `hub_r_px`, `bracelet.rows_px` (dark joint lines at an outer column) and `pieces_px` (centre-link joints, 2 px each side of the joint line, pieces x between the gap lines), `case.tip_top` / `tip_bottom` (lug end rounded up to 0.25 mm, sum a multiple of 0.25), emissions.
