## Template for the next Chronomat / chronograph Breitling variants

Navitimer B01 Chronograph 41 (AB0139211B1P1) is built by a sibling agent with its own files; another Chronomat B01 42 dial or bracelet reuses these files. Commands (lower-case sku, e.g. `ab0134101b1a1`):

```sh
sku=<sku>; ref=references/breitling-chronomat-b01-42-$sku        # holds breitling-$sku_original.webp, sources.md, REFERENCE_PLAN.md
cp config/watches/breitling-chronomat42-ab0134101b1a1-measure.json config/watches/breitling-chronomat42-$sku-measure.json   # re-measure on the new photo (list below)
python3 -B -m pipeline.breitling_chronomat42_prep $sku           # 2x copy, trace, dial_photo.jpg, steel_photo.jpg
cp config/watches/breitling-chronomat42-ab0134101b1a1.json config/watches/breitling-chronomat42-$sku.json   # trace / dial_map / steel_map paths, emissions, hands, bracelet
cp jobs/breitling-chronomat42-ab0134101b1a1.json jobs/breitling-chronomat42-$sku.json                      # replace id / output / spec / paths, keep step watch_breitling_chronomat42 and the kit preset
python3 -B -m pipeline.jobs validate jobs/breitling-chronomat42-$sku.json && python3 -B -m pipeline.jobs run jobs/breitling-chronomat42-$sku.json --force
cp outputs/jobs/breitling-chronomat42-$sku/breitling-chronomat42-$sku.glb models/watches/breitling-$sku.glb
```

The prep has the sku and the model folder (`MODEL.ref`) hard-wired like the other Breitling preps: for a different folder slug copy it once and edit `MODEL`.

**Template (keep as is, same camera framing and 10:08 pose):** the step (case from the silhouette, bezel lathe, crystal, dial lathe with the photo map, profile hands / polygon hands / hub discs, crown and pushers by `crown_parts`, bracelet with `columns` + `full` + `bounds_x_mm` + `pieces_mm`), kit preset (scale only), heights (`case`, `bezel`, `crystal`, `dial`, `hands.z`, `crown.z`, `pushers.z`), materials, pose and depth scale, steel emission 0.31, hands 0.43, dial 0.33 (black dial; check a light dial both ways), pushers geometry (radial from (0, -0.51 mm) at +-30 deg, r 2.45 mm, end 25.1 mm), crown barrel, pieces / joints of this bracelet.

**Per watch (re-measure on the photo, never copy):** scale (circle fit to the left silhouette away from the rider tab, `bezel_out_circle_px`), pivot (centre-line crossing of hour / minute), ring centre and the ring radii (radial scans), hands (rotated strips: `hands.profile`, `hands.lume`, polygons for the sub-dial hands and `hands.discs` at the hub pin dots), crown box and `right_override_px` rows / lines (pusher rows and crown rows; guards stay in the silhouette), pusher axis (silhouette scan along the axis: end distance, half width), lug rows (`tip_top` / `tip_bottom` on the 0.25 mm grid), bracelet rows (vertical brightness profiles at several x for the dark joint lines, horizontal gradient scans for the joint columns; between-lug rows get the x limits as 3rd / 4th piece entries), dial emission (colour dependent), anything else on the dial that moves (a different sub-dial layout, subseconds).
