## Template for the next Navitimer / leather-strap chronograph Breitling variants

Another Navitimer B01 (a different dial, size or strap) or the Chronomat B01 with a leather strap follows with these files; steel-bracelet variants use the column bracelet of `../../breitling-superocean-heritage-42-ab2010121b1a1/baseline/BASELINE.md` instead of `strap.kind` "leather".

```sh
sku=<lower-case sku, letters and digits only>            # e.g. ab0138211b1x1
ref=references/breitling-<model-slug>-$sku                  # folder that already holds breitling-$sku_original.webp
cp pipeline/breitling_navitimer41_prep.py pipeline/breitling_<model>_prep.py       # edit MODEL (ref, name, case_mm) and the default sku only; once per model
cp config/watches/breitling-navitimer41-ab0139211b1p1-measure.json config/watches/breitling-<model>-$sku-measure.json   # MEASURE every value again on the new photo (list below)
python3 -B -m pipeline.breitling_<model>_prep $sku        # 2x copy, trace (silhouette, cutters), dial_photo.jpg, steel_photo.jpg
cp config/watches/breitling-navitimer41-ab0139211b1p1.json config/watches/breitling-<model>-$sku.json   # change model, trace, dial_map, steel_map, verified_mm, ring_centre_mm, case tips, bezel rings / teeth, hands, polygons, discs, crown, pushers, strap
cp jobs/breitling-navitimer41-ab0139211b1p1.json jobs/breitling-<model>-$sku.json     # replace the id / output / spec / trace strings; step stays watch_breitling_navitimer41
cp config/presets/watch_kit_white_front_breitling_navitimer41.json config/presets/watch_kit_white_front_breitling_<model>.json   # scale = 2 x px_per_mm of the trace, nothing else
python3 -B -m pipeline.jobs validate jobs/breitling-<model>-$sku.json && python3 -B -m pipeline.jobs run jobs/breitling-<model>-$sku.json --force
cp outputs/jobs/breitling-<model>-$sku/breitling-<model>-$sku.glb models/watches/breitling-$sku.glb
```

**Template (keep as is):** the step `pipeline/steps/watch_breitling_navitimer41.py` (case from the silhouette with boolean pockets, bezel lathe with optional tooth profile, crystal, dial lathe, profile hands with `offset_mm`, polygon sub-dial hands and hub discs, crown, pushers, strap kinds "leather" / "rubber" / "bracelet"), kit lighting and camera (only the scale changes), materials, pose and depth scale (0.35), heights (`case`, `bezel`, `crystal`, `dial`, `hands.z`, `crown.z`, pusher `z` 4.2), steel emission 0.31, strap emission 0.29-0.30, hands emission 0.43, dial emission 0.32 for a black dial with silver sub-dials (check another colour both ways), the comparison script conventions (2x photo shifted by (1024 - 2 px0, 1024 - 2 py0), composited on white, region means in sRGB grey).

**Per watch (re-measure on the photo, never copy):**
- Scale: circle fit to the tooth tips (or the bezel outer edge) of the left silhouette (rows around the pivot row), `bezel_out_circle_px` = [cx, cy, r], r = case diameter / 2.
- Pivot: hub disc centre and the crossing of the hour and minute centre lines (rotated strips, centre offsets by linear fit); ring centre from the circle fit (`ring_centre_mm`); rings from radial scans on the left side (use only radii inside the silhouette: beyond it the transparent pixels carry garbage colour).
- Teeth: `bezel.teeth.n` from the autocorrelation of r(theta) along the left silhouette (here 56, period 6.43 deg), phase and the 20-step profile by folding r(theta).
- Crown box and flutes; pushers: end-face centres (corner points of the end face on a 12x grid crop), angle (here +-30 deg, radial from a point on the crown axis), distance to the end face, cap radius, collar radius.
- Hands: angle, length and half widths from rotated strips (threshold 45..110 on a black dial); the central seconds hand's offset from the pivot; sub-dial needles from black blobs inside the sub-dial discs (x, tip y, ball centre and radius).
- Strap: `edge_from` (a row just beyond the lug tops where the silhouette is strap-wide), lug rows `tip_top` / `tip_bottom` (silhouette widens), strap start rows (where the transparent pockets end), ends (alpha ends minus 2 px); measure `lug_inner_px` (inner lug edges) so the prep can derive the pockets (`case_cutters_mm`).
- Emissions: region ratios with the list above; the black dial floor follows the emission, so keep the template values and report the dark-dial excess.
