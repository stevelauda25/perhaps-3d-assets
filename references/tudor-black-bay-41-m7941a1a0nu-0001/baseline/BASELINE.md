## Template for the next Black Bay 41 variants

No variant is queued; if one appears, add its registry entry (prefix `tudor-black-bay-41` / `tudor-bb41` / 41 mm is already there for `m7941a1a0nu`; other SKU prefixes need their own entry in `config/watches/tudor-models.json`), then for `<sku>` = `m7941....-0001`:

```sh
cp config/watches/tudor-bb41-m7941a1a0nu-0001-measure.json config/watches/tudor-bb41-<sku>-measure.json   # then check the values on the new photo
python3 -B -m pipeline.tudor_bb41_prep <sku>        # 2x copy, trace, dial_photo.jpg, steel_photo.jpg
cp config/watches/tudor-bb41-m7941a1a0nu-0001.json config/watches/tudor-bb41-<sku>.json
# in the new spec change: model, note, trace, dial_map, steel_map (paths with <sku>), dial.emission, hands.emission, then what the checks below show
cp jobs/tudor-bb41-m7941a1a0nu-0001.json jobs/tudor-bb41-<sku>.json                                     # replace the id string everywhere (incl. references), keep step watch_tudor_bb41
# kit preset: reuse config/presets/watch_kit_white_front_tudor_bb41.json when the pivot is at (451, 610) and the scale is 13.7268; otherwise copy it and set the scale / centre
python3 -B -m pipeline.jobs validate jobs/tudor-bb41-<sku>.json
python3 -B -m pipeline.jobs run jobs/tudor-bb41-<sku>.json          # add --force after regenerating the maps
cp outputs/jobs/tudor-bb41-<sku>/tudor-bb41-<sku>.glb models/watches/tudor-<sku>.glb
```

Template (same for any Black Bay 41 photo with this crop and the 10:10:38 pose; verify by diffing the render against the 2x photo padded with offset (+122, -196) for pivot (451, 610)): measure JSON pivot, `case_edge_left_x`, `rings`, `crown`, hand tips / tails / `hub_r`, `tip_rows_px`; spec case (tips, z values), bezel, crystal, `ring_centre_mm`, crown, bracelet section structure (columns, z values), hands profiles and lume polygons, materials, pose, steel emission 0.31 / specular 0. Per variant: the dial map and bezel colours (texture only, so only emission changes; a lighter dial wants more than 0.29, check bright and dark areas), `hands.emission` (0.355: the lume saturates, lower until hands + hub reads about 1.00), hand angles and lengths if the time differs, hub radius, and the bracelet joints if the bracelet differs (brightness scans down x 350 / 450 / 550 with dark runs, plus 3-6x pixel-grid crops; mm = (px - pivot) / 13.7268; `pieces_mm.<kind>.top|bottom` = chain of [y0, y1] from the case outward, outer starts at the lug tip row `tip_top` / `tip_bottom`, centre starts under the case; `bounds_x_mm` = the two dark vertical joint lines at x about 387 / 514.5). A different strap kind: set `columns` to the column kinds left to right (`["strap"]` for a continuous strap, `pieces_mm.strap`, `z_strap`).
