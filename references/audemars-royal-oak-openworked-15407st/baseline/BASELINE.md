## Template for the next Royal Oak openworked 41 variants

Other openworked 41 mm references (for example other dial colours of the same case) need only a new variant key, measure / spec / job JSON:

```sh
key=15407st-<variant>                                    # ref folder references/audemars-royal-oak-openworked-<variant key>/ with audemars-$key_original.png and _1200x1626.png (the prep builds the path as <ref prefix>-<key>; this build used key 15407st and the folder audemars-royal-oak-openworked-15407st)
cp config/watches/audemars-royaloakopenworked41-15407st-measure.json config/watches/audemars-royaloakopenworked41-$key-measure.json   # re-measure every value on the new photo
python3 -B -m pipeline.audemars_royaloakopenworked41_prep $key                    # check the printed scale_px_per_mm (about 7.0)
sed "s/15407st/$key/g" config/watches/audemars-royaloakopenworked41-15407st.json > config/watches/audemars-royaloakopenworked41-$key.json   # then edit tip_top / tip_bottom, opening, hands profile, dial emission
sed "s/15407st/$key/g" jobs/audemars-royaloakopenworked41-15407st.json > jobs/audemars-royaloakopenworked41-$key.json
python3 -B -m pipeline.jobs validate jobs/audemars-royaloakopenworked41-$key.json && python3 -B -m pipeline.jobs run jobs/audemars-royaloakopenworked41-$key.json --force
```

Template (keep): shared step, kit lighting, heights, steel emission 0.31, hands emission 0.45, the white compositing of the dial map. Per photo: pivot (hub dot), anchor rows, octagon flats, opening circle, screw centroids (colour of the screws changes with the metal), crown, seams and bars, hand angles / lengths / widths, dial emission (try two values both ways). Copy the kit preset when the printed scale differs from 6.9958 (set scale = 2 x it and the 2x pivot to (640, 640)).
